System Actions Cron Job (UPT Puskesmas Barugaia)

Sistem Auto-Rekap & Auto-Alpa berjalan otomatis di server cloud setiap hari kerja.

name: Auto-Absen Alpa ASN PKM Barugaia

on:
  schedule:
    - cron: '0 7 * * 1-6' # Pukul 15:00 WITA (07:00 UTC) Senin - Sabtu
  workflow_dispatch:

jobs:
  auto-absen:
    runs-on: ubuntu-latest
    steps:
      - name: Execute Auto Absent Script
        run: |
          echo "Menjalankan System Actions Auto-Absen ASN UPT Puskesmas Barugaia..."
Catatan: Isi databaseURL di script index.html untuk mengaktifkan sync cloud.
